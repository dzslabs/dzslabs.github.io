Frequently asked questions

What is Retail Labeler?

Retail Labeler is a Google Sheets add-on that helps retailers design, customize and print product, price and barcode labels using information from their product catalog.

Do I need an existing product catalog?

You can use an existing Google Sheets product catalog or start with a basic catalog structure.

Can I create my own label templates?

Yes. You can choose a common size preset or define custom dimensions, add text, dynamic product fields, barcodes and images, then save your design for future use.

Can I create multiple designs for the same label size?

Yes. You can create and save multiple templates using the same physical label dimensions.

Which printing formats are supported?

The supported options include compatible thermal/roll formats, selected pre-cut label sheets and standard A4 or US Letter sheets. Available options depend on the physical dimensions of your selected template.

Does Retail Labeler print directly to my printer?

Retail Labeler generates print-ready PDFs. You use your normal printer and PDF printing workflow. Direct printer-driver integration is not required.

Does it generate official UPC or EAN numbers?

Retail Labeler can display existing UPC/EAN barcodes and support internal Code 128 barcodes. It does not issue official GS1 product identifiers.

Is Retail Labeler an inventory management system?

No. Retail Labeler is designed specifically for product label creation and printing. It does not manage inventory quantities, purchasing or stock replenishment.

Can I use Retail Labeler on mobile?

The Google Sheets add-on experience is designed for desktop use.
