This Product Privacy Notice explains how Slides from Photos, a Google Slides add-on operated by DZS Infinity LLC under the DZS Labs brand, accesses, uses, stores, and shares information when you use the add-on.
This notice supplements the general DZS Labs Privacy Policy available at:

## 1. About Slides from Photos
Slides from Photos is a Google Slides Editor add-on that helps users turn selected photos into Google Slides, creating one photo per slide.
Users can select photos from:
- Google Drive;
- Google Photos; or
- their computer.
The add-on also provides features including:
- configurable photo ordering;
- Fit and Fill image placement;
- batch progress tracking;
- Resume for supported interrupted jobs;
- photo-set verification; and
- completed, skipped, and failed processing status.

## 2. Google Permissions Used by Slides from Photos
Slides from Photos requests only the Google permissions required to provide its disclosed functionality.
The production application uses the following OAuth scopes:
Google Slides
https://www.googleapis.com/auth/presentations
Slides from Photos uses this permission to create and update slides in the Google Slides presentation being processed by the user.
The add-on uses this access only to provide the photo-to-slides functionality requested by the user.
Google Drive
https://www.googleapis.com/auth/drive.file
Slides from Photos uses this permission when the user selects photos from Google Drive.
This permission is limited to files that the user selects, creates, or otherwise makes available to the application through Google's supported file-selection and authorization mechanisms.
Slides from Photos does not request the broad Google Drive scope or the drive.readonly scope.
Google Photos Picker
https://www.googleapis.com/auth/photospicker.mediaitems.readonly
Slides from Photos uses this permission when the user explicitly chooses Google Photos as the photo source.
The application processes media items selected by the user through the Google Photos Picker for the purpose of creating the requested slides.
Slides from Photos does not use this permission to browse the user's entire Google Photos library independently of the user's selection.
External requests
https://www.googleapis.com/auth/script.external_request
This permission allows the add-on to make network requests required for supported product functionality.
It does not itself provide access to additional Google Account data.
Any Google user data obtained through Google APIs remains subject to the uses and restrictions described in this notice.
Google Slides container interface
https://www.googleapis.com/auth/script.container.ui
Slides from Photos uses this permission to display and operate its user interface within Google Slides.
This permission is used to provide the add-on interface and does not provide general access to unrelated Google Account data.

## 3. Google User Data We Access
Depending on the source and features selected by the user, Slides from Photos may process the following Google user data.
Google Slides data
The add-on may access information required to create or update slides in the presentation in which the user is working.
This access is used to:
- create slides;
- place selected photos onto slides;
- apply the selected Fit or Fill behavior;
- continue supported batch operations; and
- report processing results.
Google Drive data
When Google Drive is selected as the source, Slides from Photos processes only the Drive files the user chooses or otherwise makes available to the application.
This may include information necessary to process the selected files, such as file content and associated file metadata required for the requested operation.
Google Photos data
When Google Photos is selected as the source, Slides from Photos processes only media items explicitly selected through the Google Photos Picker.
The selected media is used to create the slides requested by the user and to support the associated batch workflow.

## 4. Photos Selected From Your Computer
Slides from Photos also allows users to select image files from their computer.
These files are not accessed through Google Drive or Google Photos permissions.
Local files are processed only after the user explicitly selects them for use with Slides from Photos.
They are used for the requested photo-to-slides operation and related batch functionality.

## 5. How We Use Your Data
Slides from Photos uses information only as necessary to provide and maintain its user-facing functionality.
This includes using selected photos and related information to:
- create one slide per selected photo;
- determine the selected photo order;
- apply Fit or Fill placement;
- track batch progress;
- continue supported interrupted batches;
- verify that a resumed batch corresponds to the originally selected photos;
- identify processing problems;
- calculate completed, skipped, and failed items; and
- display the final processing result.
Google user data is not used for unrelated purposes.

## 6. Raw, Aggregated, Anonymized, and Derived Google User Data
Slides from Photos accesses the raw Google user data described in this notice only as necessary to provide the user-facing functionality requested by the user.

Slides from Photos does not request separate aggregated or anonymized datasets from Google APIs.

The product may generate limited derived operational information necessary to provide batch processing, progress, Resume, verification, recovery, and processing-result functionality.

Raw Google user data, and any information aggregated, anonymized, de-identified, or derived from that data, remains subject to the same use, transfer, security, retention, and Limited Use restrictions described in this notice.

Slides from Photos does not use raw, aggregated, anonymized, de-identified, or derived Google user data for advertising, profiling, data brokerage, creditworthiness, lending, or unrelated purposes.

## 7. Batch Progress and Resume Data
Slides from Photos maintains limited processing state and job metadata necessary to provide batch progress, Resume, photo-set verification, recovery from supported interruptions, and processing-result functionality.

Depending on the workflow, this operational information may include batch progress, item-level processing status, verification information used to confirm that a resumed batch corresponds to the originally selected photo set, and completed, skipped, or failed processing results.

This batch state may be derived from or associated with the photos and Google resources selected by the user, but it is used only to operate and maintain the user-requested Slides from Photos workflow.

Slides from Photos does not use batch or job information for advertising, profiling, data brokerage, creditworthiness, lending, generalized AI/ML model training, or unrelated purposes.

The job state is separate from the user's Google authorization. Revoking Google authorization does not by itself guarantee immediate deletion of existing batch state where that state remains reasonably necessary or legally permitted, as further described in the retention, removing-access, and deletion sections of this notice.

## 8. Data Storage and Retention
Slides from Photos retains information only for as long as reasonably necessary to provide the user-requested functionality, including supported batch processing, Resume, verification, recovery, and processing-result functionality.

Limited batch state and job metadata may remain available when reasonably necessary to allow a user to continue or recover a supported interrupted job.

Slides from Photos does not retain Google user data or derived batch information for advertising, profiling, data brokerage, creditworthiness, lending, generalized AI/ML model training, or unrelated purposes.

When stored information is no longer reasonably necessary for its disclosed product purpose, it is deleted, anonymized, or otherwise handled in accordance with applicable law, Google platform requirements, and the DZS Labs Privacy Policy.

Users may contact DZS Labs regarding applicable stored product information or deletion requests using the contact information provided in this notice.
